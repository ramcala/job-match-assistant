Connect your Gmail account

The extension is implemented, but you must register your own Google OAuth client once. No client secret or Gmail password belongs in this extension.

  1. Keep the extension in its existing folder. Copy its ID from chrome://extensions or the extension Settings page.
  2. Open Google Cloud Console, select/create a project, and enable the Gmail API.
  3. Configure Google Auth Platform branding/audience (OAuth consent screen). For personal external testing, add your Gmail address as a test user.
  4. Configure data access for https://www.googleapis.com/auth/gmail.send and https://www.googleapis.com/auth/userinfo.email.
  5. Create an OAuth client of type Web application. Add the exact Authorized redirect URI shown in extension Settings (including /gmail). Google generates the client ID.
  6. Paste the generated client ID into extension Settings and click Save Gmail client ID. Do not enter a client secret. No manifest editing is needed.
  7. Reload the extension in chrome://extensions and approve new permissions if Chrome asks. Refresh LinkedIn.
  8. Open extension Settings and click Connect Gmail. Complete Google's consent screen. The connected email is displayed after verification.

If the extension ID changes, update the authorized redirect URI in Google Cloud. Existing Chrome Extension OAuth clients cannot be used in this saved-ID flow; create a Web application client once. For distribution, maintain a stable extension ID and follow Google's OAuth verification requirements for sensitive scopes. Organization policies may restrict approval.

Send an application

Analyze a post, enter the verified recruiter address, and choose Prepare email to send here. Edit the subject/body, choose whether to attach your saved resume, then Review email. Check From, To, attachment and content, then click Send this email. Gmail returns a message ID on success. No automatic retries are made. For uncertain delivery, check Gmail Sent before preparing another copy.

Google authorization may open a Google-controlled consent screen; analysis remains in the extension toolbar popup. Sign-in uses Chrome Identity; short-lived tokens stay in extension session storage and expire. Reconnect after expiry or a browser restart. The client ID stays in local settings across reloads and updates. The app stores the last send status locally and review snapshots in session storage. It does not read your inbox. The saved resume is attached only when selected.

Disconnect locally clears cached authorization. Revoke the Google grant from your Google account connections if desired.
