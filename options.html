API billing · API usage

About the ChatGPT/Gemini browser-session modes: picking one of these in the popup opens a new background tab at chatgpt.com or gemini.google.com, types in your resume and the job post, submits it, and reads the reply back — no API key needed, but you must already be signed in to that site in this browser. Keep the extension popup open until it finishes (up to ~2 minutes); the AI tab is left open afterward so you can review the conversation. This automates the consumer web app rather than an official API — most providers' terms of service don't cover that, which is a risk to your own account there — and it depends on that site's current page layout, which changes without notice.

Applied jobs backup

Keeps one always-current file outside Chrome, so your applied list survives a Chrome reinstall or a removed extension. Restore it anytime from the popup's Restore button. If Chrome is set to ask where to save each download, this may prompt each time.

Email finder (optional)

Adds a Find email button to each analysis. Uses Hunter.io — sign up (free tier available), then copy your key from Hunter’s API dashboard. LinkedIn never exposes a poster’s email, so this looks up likely recruiter/company emails by company domain or name; always verify before sending.

Apollo and RocketReach match a specific person, so fill the hiring contact name in the analysis before Find email. Hunter can also search by company domain alone.

Easy Apply autofill (LinkedIn)

Saved answers the "⚡ Auto Easy Apply" button uses to fill LinkedIn Easy Apply forms. It fills only fields it can confidently match and stops rather than guess when a required field is blank.

When Easy Apply pauses on a new screening question, answer it in the dialog, then click Remember my answers on the on-page card — it learns the answer for next time.

Job search shortcut

Used by the "Job boards" buttons in the popup to open each site pre-filled with this search. Leave blank to open each board's home page.

Portable folder (switch laptops)

Link a folder once — ideally one inside Google Drive, Dropbox or OneDrive — and everything (resume, settings, applied jobs, saved emails) is saved to a file there. On another laptop, link the same synced folder and click Load from folder. This keeps your data outside Chrome so it survives a reinstall or a new machine.

Privacy: job and resume text go to OpenAI only in API mode, and to ChatGPT or Gemini only in the corresponding browser-session mode. Google receives your reviewed email and selected attachment when you click Send.
